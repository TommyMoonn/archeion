## Changes

- Improved secondary-text readability across built-in application and Reader themes.
- Long dialog headings, book titles, authors, filenames, and metadata preview values now wrap instead of overflowing or being clipped.
- Action lists now expose standard disclosure and button behavior consistently to keyboard and screen-reader users.
- Library multi-selection actions no longer announce unsupported toolbar keyboard behavior.
- Failed bulk metadata updates are now announced without moving keyboard focus.
