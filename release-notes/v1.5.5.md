## Changes

- Search the documentation by section title or page content, with keyboard navigation and compact or detailed results.
- Copy a documentation page as Markdown, including its headings, links, lists, and code examples.
- Added guides for Quick Actions and EPUB metadata and covers, plus expanded guidance on archive health, recovery, data ownership, and annotation exports.
- Documentation pages have a revised reading layout, clearer navigation, heading links, and an outline that follows the section you are reading.
- Browse release history in the documentation, with dated changes and links to each GitHub release.
- The Reader's progress control now reports the current reading position to screen readers while a different position is being previewed or a jump is still pending.
- Confirmations for deleting a Reader note or clearing a book's reading progress now start with Cancel focused.
- Compact Library navigation keeps its labels and current-page state when the sidebar is collapsed. Toggle controls keep stable names and expose their selected state.
- The website Reader demo and mobile navigation have more consistent keyboard controls, announced states, and focus handling.
