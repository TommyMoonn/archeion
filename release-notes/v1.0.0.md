## Changes

- Redesign Quick Actions for faster keyboard-driven commands.
- Manage archives, themes, display density, animations, and collection views from Quick Actions.
- Add a configurable `Ctrl+B` shortcut for the Library sidebar.
- Improve Reader panels, focus return, Escape behavior, and temporary surfaces.
- Improve note autosave, draft recovery, retry handling, and annotation management.
- Simplify bookmark and annotation feedback while keeping Undo where useful.
