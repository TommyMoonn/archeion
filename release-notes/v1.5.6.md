## Changes

- Compare themes using compact previews beneath each theme name and a larger preview showing how the selected theme looks across navigation and workspace areas.
- Library and Archive Manager now have a flush navigation/workspace layout instead of a framed, inset workspace.
- The Library titlebar now contains the Archeion name and sidebar toggle. Open Quick Actions with **Ctrl + Shift + P**, or your configured shortcut.
- Use **Reveal archive folder** in the archive switcher to open the active archive's location.
- Custom themes retain clear navigation/workspace boundaries even when those areas use the same color. Theme warnings also check the readability of muted navigation text.
- Controls and labels use lighter text emphasis, and ordinary action icons have more consistent outlines. Text sizes, sidebar dimensions, Library headings, and Reader publication fonts are unchanged.
