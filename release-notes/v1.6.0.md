## Changes

- Install **1.6.0 manually once** to enable in-app updates for future releases. Existing 1.5.x versions cannot install this update from inside Archeion.
- Archeion automatically checks for stable updates. Turn this off in **Settings → General → Automatically check for updates** if you prefer manual checks.
- Available updates appear at the bottom-right of the Library without interrupting Reader. Choose **Later** to postpone that version's notification for 24 hours.
- **Update now** downloads and verifies the update while you keep using Archeion. Choose **Restart now** when it is ready to install and reopen the app; restarting is always your decision.
- Check for updates manually in **About**, even when automatic checks are off or a notification is postponed. Open release history with **Changelog** in About or **What's new** on an update notice.
- Choose installed Windows fonts for **Interface font** and **Display font** in Appearance settings using a searchable font picker.
- Reader's **Typeface** picker now includes installed Windows fonts independently of application fonts. Missing saved fonts use a fallback without erasing your choice; restart Archeion after installing or removing fonts to refresh the list.
