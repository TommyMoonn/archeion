- Changes to different Library, Reader, or Storage settings in separate windows now remain together.
- Retry now loads Settings or Theme Manager after a temporary failure without closing the window.
- Add EPUB now starts at the archive root. A folder chosen in the dialog applies only to that import.
- Compatible theme choices from older archives remain available after upgrade.
