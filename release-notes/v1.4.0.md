- Move Settings into a standalone window that can stay open beside Archeion.

- Reorganize Settings for clearer preferences, shortcuts, archive controls, and maintenance actions.
- Move import defaults to global settings while keeping destination folders archive-specific.
- Improve archive maintenance feedback when switching between archives.
