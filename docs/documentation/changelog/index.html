  1. v1.6.0

    #
    October 9, 2026
    • Install 1.6.0 manually once to enable in-app updates for future releases. Existing 1.5.x versions cannot install this update from inside Archeion.
    • Archeion automatically checks for stable updates. Turn this off in Settings → General → Automatically check for updates if you prefer manual checks.
    • Available updates appear at the bottom-right of the Library without interrupting Reader. Choose Later to postpone that version's notification for 24 hours.
    • Update now downloads and verifies the update while you keep using Archeion. Choose Restart now when it is ready to install and reopen the app; restarting is always your decision.
    • Check for updates manually in About, even when automatic checks are off or a notification is postponed. Open release history with Changelog in About or What's new on an update notice.
    • Choose installed Windows fonts for Interface font and Display font in Appearance settings using a searchable font picker.
    • Reader's Typeface picker now includes installed Windows fonts independently of application fonts. Missing saved fonts use a fallback without erasing your choice; restart Archeion after installing or removing fonts to refresh the list.

    Full release notes for v1.6.0 ↗

  2. v1.5.6

    #
    October 6, 2026
    • Compare themes using compact previews beneath each theme name and a larger preview showing how the selected theme looks across navigation and workspace areas.
    • Library and Archive Manager now have a flush navigation/workspace layout instead of a framed, inset workspace.
    • The Library titlebar now contains the Archeion name and sidebar toggle. Open Quick Actions with Ctrl + Shift + P, or your configured shortcut.
    • Use Reveal archive folder in the archive switcher to open the active archive's location.
    • Custom themes retain clear navigation/workspace boundaries even when those areas use the same color. Theme warnings also check the readability of muted navigation text.
    • Controls and labels use lighter text emphasis, and ordinary action icons have more consistent outlines. Text sizes, sidebar dimensions, Library headings, and Reader publication fonts are unchanged.

    Full release notes for v1.5.6 ↗

  3. v1.5.5

    #
    October 5, 2026
    • Search the documentation by section title or page content, with keyboard navigation and compact or detailed results.
    • Copy a documentation page as Markdown, including its headings, links, lists, and code examples.
    • Added guides for Quick Actions and EPUB metadata and covers, plus expanded guidance on archive health, recovery, data ownership, and annotation exports.
    • Documentation pages have a revised reading layout, clearer navigation, heading links, and an outline that follows the section you are reading.
    • Browse release history in the documentation, with dated changes and links to each GitHub release.
    • The Reader's progress control now reports the current reading position to screen readers while a different position is being previewed or a jump is still pending.
    • Confirmations for deleting a Reader note or clearing a book's reading progress now start with Cancel focused.
    • Compact Library navigation keeps its labels and current-page state when the sidebar is collapsed. Toggle controls keep stable names and expose their selected state.
    • The website Reader demo and mobile navigation have more consistent keyboard controls, announced states, and focus handling.

    Full release notes for v1.5.5 ↗
