Manage books and folders

Rename, move, reveal, export, and delete files in the active archive.

On this page

Archeion's file actions change the real EPUB files and folders inside the archive.

Manage a book

#

Rename or move

#

Use the book action menu or Details drawer to rename an EPUB or move it to another folder in the same archive. Moving changes the file's location; it does not export a second copy or change the embedded title. Check the destination before confirming, especially when a file with that name already exists.

To change the title or embedded image without renaming the file, use Metadata and covers. Those edits write into the EPUB; review their previews and backup guidance before saving.

Reveal or export

#

Use Reveal in folder to open the file's location in Windows Explorer. Selection mode can export selected EPUB files to another location without changing the files in the archive. Export is a copy, not a complete archive backup: it does not include the archive's reading data or sidecars. Use the Annotation export reference for separate Markdown or JSON exports, or Archive storage to preserve the whole archive.

Delete a book

#

Deletion is shown as Delete to Recycle Bin. Review the confirmation before deleting one or more books. This removes the real files from their archive locations, not just cards from the current view. Check the reported result before assuming every selected item was deleted.

If the file was already deleted outside Archeion, use Remove metadata to clear its old Library entry. Removing metadata is not file recovery and does not bring back the EPUB. If you want to restore the book or retain its reading data, consult safe recovery steps before removing the entry.

Manage folders

#

Folder operations include their contents.

Folder actions work on real directories. Moving a folder also moves the EPUB files and subfolders inside it.

Review a folder before deleting it.

Check the folder contents before deleting it. A folder deletion can include every book and subfolder inside that folder.

Changes made outside Archeion

#

Refresh the Library

#

Archeion normally detects files added, moved, renamed, or removed with Windows Explorer. Use Rescan archive when the Library does not reflect an external change.

Back up before large changes

#
Copy the complete archive

For a complete backup, copy the EPUB folders and the hidden .archeion folder together.

If a file is missing or a move or scan fails, follow Troubleshooting and recovery before removing metadata or modifying sidecars. For duplicate-file decisions, see compare duplicate groups.
