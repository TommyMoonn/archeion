Using Archeion

Open footnotes and illustrations

Read linked notes without losing your place and inspect supported book images closely.

On this page

Reader keeps temporary footnote and illustration surfaces above the active book so you can inspect supporting content without reopening the EPUB or losing the current session.

Read a Footnote

Select a supported footnote or endnote link to open the Footnote popover near the reading position. The popover can preserve ordinary text, lists, emphasis, links, and supported local images from the note.

Close the popover to return focus to reading. Following a supported internal link from a note uses normal Reader navigation, so the jump can be retraced with Reader history.

Open an Illustration

Supported standalone book images can open in the focused Illustration viewer. Pointer activation and keyboard activation with Enter or Space use the same viewer.

Large reflowable illustrations may be constrained to the visible Reader area for normal reading, while smaller images are not deliberately enlarged. Open the focused viewer when you want to inspect the image independently of the page presentation.

Zoom and pan

  • Fit to viewport fits the image inside the viewer.
  • Actual size shows the image at its natural pixel size.
  • Zoom in and Zoom out adjust the scale within safe limits.
  • When the image is larger than the viewport, drag to pan around it.
  • Reset returns to the fitted view.

Save the original image

When export is available, choose Save image to save the original local image resource without taking a screenshot or re-encoding the displayed view. Archeion supports original AVIF, GIF, JPEG, PNG, and WebP resources on this export path.
