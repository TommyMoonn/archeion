Using Archeion

Browse and organize the Library

Find books, use folders, change the layout, and manage one or more books.

On this page

The Library shows the EPUB files and folders in the active archive.

Navigate the Library

Main views

  • Library shows the active collection.
  • Favorites shows books marked as favorites.
  • Folders follows the archive's folder structure.

Smart Views

Smart Views show focused groups such as books in progress or books with missing metadata. You can choose which Smart Views appear from Settings.

Find books

Search and filter

Use Search books to narrow the current view. Filters can be combined for series, subject, language, publisher, reading status, favorites, and missing information.

Sort and change the layout

Use the sort selector to change the order. Switch between Grid and List view without changing the books included in the current view.

Manage books

Work with one book

Open a book's action menu to:

  • Read the book.
  • Add or remove it from Favorites.
  • Open Details.
  • Rename or move the file.
  • Reveal it in Windows Explorer.
  • Delete it, or remove its old Library entry when the file is already missing.

Work with multiple books

Select Select books in the toolbar. The bulk action bar can update favorites, move books, edit or refresh metadata, regenerate covers, export files or annotations, and delete selected books to the Recycle Bin.

Manage folders

Folder actions work on the real folders inside the archive. You can create, rename, move, reveal, or delete folders when the action is available. Do not place books or personal files inside .archeion.

Use Quick Actions

Press Ctrl + Shift + P to open Quick Actions and search the commands available on the current screen.
