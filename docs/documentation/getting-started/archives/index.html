Getting started

Open or create an archive

Connect Archeion to an existing EPUB folder or create a new archive.

On this page

An Archeion archive is a real folder. You can open a folder that already contains EPUB files or create a new folder and add books later.

Open an existing folder

  1. Open Archive Manager.At startup, or from the Library archive switcher, choose Manage archives.
  2. Select Open archive.Choose the folder that should act as the archive root.
  3. Let Archeion scan the folder.EPUB files and nested folders appear in the Library while Archeion prepares metadata and covers.
Your folder structure stays intact

Archeion treats existing folders as library folders. It does not require you to flatten or reorganize the collection.

Create an empty archive

  1. Choose Create empty archive.Archive Manager opens the creation form.
  2. Enter an archive name.The name becomes the new folder name.
  3. Choose a parent location.Archeion shows the final path before creation.
  4. Create the archive.The new folder becomes active and is ready for EPUB files.

Manage known archives

Archive Manager keeps a list of known archives. For each entry, you can:

  • Activate the archive.
  • Rename its display name.
  • Reveal its folder in Windows Explorer.
  • Forget the entry without deleting the archive folder.

If a known archive folder is moved or removed outside Archeion, the entry is marked as missing instead of silently disappearing.

The .archeion folder

After an archive is used, Archeion may create a hidden .archeion directory inside it. This directory stores app-managed state. Do not place books inside it, and include it when backing up or moving the complete archive.
