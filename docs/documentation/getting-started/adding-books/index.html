Getting started

Add EPUB files

Add books to the active archive by copying or moving them.

On this page

Use Add EPUB when you want Archeion to place books in the archive for you.

Add books in Archeion

Choose files and a destination

  1. Select Add EPUB.The button is in the Library toolbar.
  2. Choose one or more files.Select the .epub files you want to add.
  3. Choose a destination.Add EPUB starts at the archive root. Choose an existing folder if this import belongs there.
  4. Choose what to do with filename conflicts.Select the option you want when a file with the same name already exists.
  5. Select Copy or Move.Copy keeps the original file. Move transfers it into the archive.
  6. Confirm Add EPUB.Archeion adds the files and refreshes the Library.

Copy or move

Use Copy when you want to keep the original file. Use Move when the archive should become the file's new location. The default import mode and filename-conflict choice come from application-wide Archives settings. A destination chosen in the dialog applies to that import only.

Check the destination before moving files

A move removes the source file after it has been placed in the archive.

Handle existing filenames

When the destination already contains the same filename, use the conflict option shown in the dialog. Review replacement confirmations carefully because replacing a file is destructive.

Organize books

Create a folder first

Use the plus button beside Folders in the Library sidebar. The new folder can then be selected as the destination when adding books.

Add files with Windows Explorer

You can copy EPUB files directly into the archive folder. Archeion normally detects the change. Use Rescan archive from the Library toolbar when a new or moved file does not appear.
