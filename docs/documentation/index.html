On this page

Archeion is a local-first Windows desktop app for organizing and reading EPUB libraries. These guides cover the workflows needed to create an archive, add books, browse the library, read and annotate, manage files, and customize appearance.

Current scope

This documentation reflects Archeion 0.4.0. Archeion currently targets Windows 11 on x64 systems and supports EPUB files.

Start here

01 Install Archeion Choose the EXE or MSI package and complete the Windows installation. 02 Open or create an archive Use an existing EPUB folder or start with a new local folder. 03 Add EPUB files Copy or move books into the archive and control filename conflicts. 04 Read and annotate Use paged or continuous mode, bookmarks, highlights, notes, and exports.

Core concepts

Archive

An archive is a normal folder that contains your EPUB files and nested folders. Archeion keeps the filesystem understandable outside the app instead of importing books into a private database.

Active archive

Archeion works with one active archive at a time. Use the archive switcher in the Library sidebar or open Manage archives to switch, create, rename, reveal, or forget archives.

Sidecar data

Archeion stores library state, reading progress, annotations, settings, caches, backups, and custom theme packages inside a hidden .archeion folder beside your books. Copy that folder with the archive when you want to preserve the complete Archeion state.
