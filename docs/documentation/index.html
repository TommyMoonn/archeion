Archeion documentation

Guides for installing Archeion, setting up an archive, reading, organizing files, and customizing the app.

On this page

Start with installation and archive setup, or choose a guide for the task you want to complete.

Supported platform

These guides cover Archeion on Windows 11 x64. Archeion supports EPUB files.

Getting started

#

Follow these guides in order to set up your first library.

  • Install Archeion: choose and run the Windows installer.
  • Open or create an archive: choose your EPUB folder.
  • Add EPUB files: copy or move books into the archive.

Using Archeion

#
  • Library: find, filter, select, and organize books.
  • Archive health: review Duplicates and EPUB Issues before changing files.
  • Quick Actions: find commands and choose options from the keyboard.
  • Metadata and covers: review metadata changes and replace embedded EPUB covers.
  • Series: review volume order and continue reading.
  • Reader and annotations: read, bookmark, highlight, and export notes.
  • Reader navigation and progress: find text and retrace jumps.
  • Footnotes and illustrations: inspect supporting content without losing your place.
  • File management: rename, move, export, or delete files.
  • Settings: change preferences and active-archive options.
  • Dictionaries and Define: install, order, and repair local sources for offline Reader lookups.
  • Keyboard shortcuts: consult configurable commands and fixed interaction keys.

Customization

#
  • Appearance: choose app colors, density, and reduced-motion behavior, or adjust Reader settings.
  • Custom themes: write a theme using the supported format and color tokens.
  • Theme Manager: import, preview, apply, and update themes.

Reference

#

An archive is your EPUB folder. Archeion opens one archive at a time. The storage reference explains which data travels with it.

  • Archive storage: understand data ownership, scan behavior, backups, and maintenance.
  • Troubleshooting and recovery: choose safe actions for missing archives, stale metadata, failed scans, and interrupted edits.
  • Annotation export: understand Markdown, versioned JSON, and detached annotation records.
  • About and resources: find version information and public project links.
