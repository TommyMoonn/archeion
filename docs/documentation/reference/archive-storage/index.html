Reference

Archive storage, ownership, and maintenance

Know which data travels with an archive, which preferences live in application data, and which Storage actions operate on the active archive.

On this page

EPUB files remain normal files. Archive-specific Reader and Library sidecars live under the archive's hidden .archeion folder, while application-wide preferences, installed dictionaries, and custom theme packages live in Archeion's application data.

Archive data versus application data

Archive-owned data

The active archive's .archeion directory contains sidecars such as Library metadata, reading progress, annotations, scanner cache data, generated covers, and recovery backups. These records belong to that archive and should travel with it when you back up or move the library.

Application-wide data

Application preferences, Reader defaults, keyboard shortcuts, theme selections, custom theme packages, installed dictionaries, and standalone utility-window preferences are application-wide. Preferences are stored in the application settings.json, with custom theme packages alongside it in Archeion's application data rather than copied into each archive.

Older archives may still contain legacy .archeion/themes/ packages and archive settings files. They are migration inputs, not current preferences. Archeion can copy compatible theme packages into application data without deleting the archive copy; it retires obsolete archive settings artifacts when an archive is opened.

Back up or move an archive

Copy the complete archive folder, including hidden files, to preserve EPUBs and archive-owned metadata together. Application-wide settings, dictionaries, and global theme packages are separate and are not part of an archive backup.

Storage global policies

Open Settings → Storage for application-wide policies:

  • Scan on startup checks the active archive when it opens.
  • Live filesystem watcher refreshes the archive when files change on disk.
  • Keep EPUB writeback backup retains one recovery copy after supported metadata edits; it is off by default.

Active-archive maintenance

When an archive is active, Storage also exposes maintenance actions:

  • Archive scan: check the active archive without changing EPUB files.
  • Scanner cache: clear cached scan state so EPUBs are checked again later.
  • Source metadata: re-extract parsed EPUB title and author data.
  • Generated cover cache: review and clear generated covers for the active archive.
  • EPUB writeback backups: review and clear retained recovery copies from metadata edits.
  • Archive metadata: repair corrupted sidecar files without changing EPUB files.
  • Metadata folder: open the active archive's .archeion sidecar directory.
