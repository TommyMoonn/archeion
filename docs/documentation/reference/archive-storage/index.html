Reference

Archive storage and backups

See what an archive contains and how to back it up or move it.

On this page

Your EPUB files remain normal files and folders. Archeion stores its own data in the hidden .archeion folder inside the archive.

What an archive contains

Example layout

Your Archive/
├── Book.epub
├── Series/
│   └── Volume 01.epub
└── .archeion/
    ├── annotations.json
    ├── library.json
    ├── progress.json
    ├── scanner-cache.json
    ├── settings.json
    ├── covers/
    ├── backups/
    └── themes/

EPUB files and folders

Books stay as normal .epub files. Subfolders stay as real folders and appear in the Library folder tree. You can inspect and copy them with Windows Explorer.

The .archeion folder

Path Contains
library.json Library metadata and archive information.
progress.json Saved reading positions.
annotations.json Bookmarks, highlights, notes, and annotation recovery data.
settings.json Settings stored with the archive, including selected themes.
scanner-cache.json Cached scan information.
covers/ Generated or cached covers.
backups/ Backups created before supported book file changes.
themes/ Custom theme packages.

Back up or move an archive

Back up an archive

Copy the complete archive folder, including hidden files. The EPUB files contain the books. The .archeion folder contains progress, annotations, settings, covers, backups, and themes.

Move an archive

  1. Wait for active operations to finish.Let imports, exports, metadata changes, and cover changes complete.
  2. Move the complete archive folder.Include all EPUB folders and .archeion.
  3. Open the archive from its new location.Use Archive Manager.
  4. Forget the old missing entry if needed.This removes the old entry from Archeion. It does not delete files.

Edit files carefully

Theme files

Files inside .archeion/themes/ are intended for manual editing. See Custom themes for the supported format.

Other .archeion files

Use Archeion to change progress, annotations, settings, and metadata. Manual edits to the other JSON files can make the data invalid. Make a backup before attempting manual recovery.

Move to another computer

Copy the complete archive to the other computer, install Archeion, and open the copied folder from Archive Manager. Archeion does not provide account-based or cloud synchronization.
