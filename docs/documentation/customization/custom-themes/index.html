Customization

Custom themes

Create and manage JSON color themes for the app and Reader.

On this page

A custom theme is a theme.json file that changes supported colors. It does not change layout, fonts, motion, images, or app behavior.

Themes are stored with the archive

Custom themes are kept in .archeion/themes/ inside the active archive. Include .archeion when backing up or moving the archive.

Create a theme package

Folder structure

Create one folder for each theme directly inside .archeion/themes/:

My Archive/
└── .archeion/
    └── themes/
        └── moon-ink/
            └── theme.json

The theme folder name must match the id in theme.json.

Basic theme file

{
  "$schema": "https://tommymoonn.github.io/archeion/schemas/archeion-theme-v1.schema.json",
  "schemaVersion": 1,
  "id": "my-theme",
  "name": "My Theme",
  "base": "dark",
  "app": {
    "accent": "#8FC1E3"
  }
}

Use the theme schema

Add the published schema URL to get completion and validation in editors that support JSON Schema: 

https://tommymoonn.github.io/archeion/schemas/archeion-theme-v1.schema.json

Open the theme schema

Theme file fields

Fields and requirements

Field Required Value
$schema No The version 1 schema URL.
schemaVersion Yes 1.
id Yes 3 to 64 lowercase letters, digits, dots, underscores, or hyphens. It must match the folder name.
name Yes A one-line display name from 1 to 80 characters.
author No A one-line author name from 1 to 80 characters.
description No A one-line description from 1 to 240 characters.
base Yes dark or light.
app Yes At least one supported app color.
reader No A dark, light, or sepia base and at least one supported Reader color.

Color format

Use #RRGGBB or #RRGGBBAA. Do not use CSS variables, color names, functions, gradients, or URLs. Unknown fields and token names make the theme invalid.

Change only the colors you need

You only need to include the colors you want to replace. The selected base provides the remaining app colors. Use reader.base for the remaining Reader colors. 

{
  "schemaVersion": 1,
  "id": "blue-accent",
  "name": "Blue Accent",
  "base": "light",
  "app": {
    "accent": "#285F88"
  }
}

A custom theme cannot inherit from another custom theme.

Reader fonts, text size, spacing, and page width are controlled in Reader settings.

Colors that themes do not change

  • The Windows close button keeps its normal white-on-red hover state.
  • Annotation highlights stay yellow, green, blue, and rose.
  • Controls shown over cover images keep a white-on-black style for readability.

Add and apply a theme

Open Theme Manager

  1. Open Settings.Go to Appearance → App themes → Manage.
  2. Import a theme or open the themes folder.You can import a JSON file or edit theme folders directly in .archeion/themes/.
  3. Reload after editing.Select Reload themes after changing theme.json outside Archeion.
  4. Preview the theme.Select Keep theme to save it or Revert to restore the previous theme.
  5. Choose Reader colors.Select a compatible Reader theme from Settings or Reader settings.

Update an existing theme

If an imported theme uses an existing package ID, Archeion asks before replacing its theme.json. Other files in that theme folder are kept.

Fix an invalid theme

Theme Manager shows the problems found in invalid packages. Fix the listed fields or colors, save the file, then reload themes.

Low-contrast color combinations are shown as warnings. Review them before keeping the preview.
