Customization

Custom themes

Create archive-local JSON theme packages for the application and EPUB reader.

On this page

Archeion theme manifests are strict, color-only JSON files. They can recolor the application and EPUB reader without changing layout, typography, motion, assets, or behavior.

Themes belong to the archive

Custom theme packages are stored under the active archive's .archeion/themes/ directory. Copy the complete .archeion folder when moving or backing up selected themes and settings.

Package layout

Store each theme in one direct child directory of .archeion/themes/:

My Archive/
└── .archeion/
    └── themes/
        └── moon-ink/
            └── theme.json

The directory name must exactly match the manifest id. Archeion reads only theme.json from each direct child directory. Hidden directories and nested packages are ignored.

Schema

Use the published version 1 schema for completion and validation in JSON-aware editors: 

https://tommymoonn.github.io/archeion/schemas/archeion-theme-v1.schema.json

Open the theme schema

{
  "$schema": "https://tommymoonn.github.io/archeion/schemas/archeion-theme-v1.schema.json",
  "schemaVersion": 1,
  "id": "my-theme",
  "name": "My Theme",
  "base": "dark",
  "app": {
    "accent": "#8FC1E3"
  }
}

$schema is optional. Archeion does not download it during runtime validation.

Manifest fields

Field Required Rules
$schema No When present, use the canonical version 1 schema URL.
schemaVersion Yes Integer 1.
id Yes 3 to 64 lowercase ASCII letters, digits, dots, underscores, or hyphens. It must match the package directory.
name Yes 1 to 80 visible Unicode characters on one line.
author No 1 to 80 visible Unicode characters when present.
description No 1 to 240 visible Unicode characters when present.
base Yes dark or light. Supplies omitted application colors.
app Yes Strict object with at least one supported application color override.
reader No Strict object with a dark, light, or sepia base and at least one reader override.

Every color must use #RRGGBB or #RRGGBBAA. CSS functions, variables, keywords, gradients, URLs, unknown fields, and unknown token names are rejected.

Partial overrides

A theme only needs to provide the colors it changes. base supplies omitted application colors, while reader.base supplies omitted reader colors. 

{
  "schemaVersion": 1,
  "id": "blue-accent",
  "name": "Blue Accent",
  "base": "light",
  "app": {
    "accent": "#285F88"
  }
}

Custom themes cannot inherit from other custom themes.

Reader typography remains controlled by Reader settings and cannot be changed by a theme.

Manage themes in Archeion

  1. Open Theme Manager.Go to Settings → Appearance → App themes → Manage.
  2. Import or open the themes folder.Import a JSON manifest, or create and edit package folders in .archeion/themes/.
  3. Reload themes.After editing theme.json externally, choose Reload themes. Archeion does not continuously watch theme files.
  4. Preview the application theme.Preview is temporary. Choose Keep theme to save it, or Revert to restore the stored appearance.
  5. Choose reader colors separately.Use Settings or the Reader settings panel for compatible reader themes.

Import is create-only. If a package ID already exists, Archeion asks before updating its theme.json and preserves other files in the package.

Diagnostics and contrast

Theme Manager lists invalid packages with diagnostics so they can be repaired. Contrast findings are warnings rather than schema failures and must be acknowledged before keeping a preview with warnings.

If a selected custom package becomes missing or invalid, its ID remains stored so the selection can resume after the package is restored and reloaded.

Fixed colors

Some visual identities are intentionally not theme tokens:

  • The Windows close button keeps its platform-style white-on-red hover treatment.
  • Annotation highlights remain yellow, green, blue, and rose.
  • Cover-image controls keep a neutral white-on-black treatment for legibility over artwork.
