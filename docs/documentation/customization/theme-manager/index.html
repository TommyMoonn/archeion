Theme Manager

Manage application-wide custom theme packages in a standalone window without depending on the active archive.

On this page

Manage application-wide custom theme packages in a standalone window without depending on the active archive.

Open Theme Manager

Open Settings → Appearance and select Manage themes. Theme Manager opens in its own window and can remain open beside the Library and Settings. Opening it again focuses the existing window.

Manage theme packages

  • Import adds a theme.json file to Archeion's global theme catalog.
  • Reload themes rereads the catalog after external edits.
  • Open themes folder opens the theme-package directory inside Archeion's application data.
  • Select a theme to inspect it. Preview changes stay temporary until you choose Use theme.
  • Importing the same package ID asks whether to Update theme; deleting removes the selected custom package.

Application-wide storage and legacy copies

Custom theme packages are stored in Archeion's application data, not in the active archive's .archeion/themes/ folder. This keeps the same catalog available across archives and standalone windows.

When Archeion finds compatible legacy theme packages in registered older archives, it can copy them into global application data. The original archive copies are left in place; migration does not delete or rewrite those legacy packages.

For the package format and supported color tokens, see Custom themes.
