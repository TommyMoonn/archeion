Appearance and reader controls

Choose app colors, Display density and Animations, or adjust Reader colors and typography.

On this page

Choose app colors

#

Open Settings → Appearance and use App themes. Built-in themes are available immediately; System follows the operating system's light or dark appearance. The app theme affects the interface, not the EPUB's text size or reading layout.

For custom packages, open Theme Manager to import, preview, and apply colors. Packages can provide supported app and Reader colors, but cannot add CSS, scripts, fonts, images, or layout changes. Authors can consult the Custom themes format and tokens.

Adjust spacing and motion

#

Display density changes spacing in the app interface. Comfortable gives controls more room; Compact brings controls and collection items closer together. Density does not change the EPUB's typography or Page Width. Use Reader settings for those.

Motion is enabled only when Animations is on and the operating system is not requesting reduced motion. Turning Animations off suppresses motion; turning it on does not override the system's reduced-motion preference. This controls subtle application transitions, not Reader content animation or automatic page turning.

Adjust Reader colors and layout

#

Choose a Reader theme from Settings → Reader or the Reader settings panel. Reader colors are separate from App themes, so changing one does not require changing the other.

Open Reader settings to change typeface, text size, line spacing, Page Width, reading mode, and progress placement. Custom theme files do not set these options. See Reader settings and reading-width limits for their effects.

Change collection presentation

#

Use the Library toolbar to switch Grid and List views, sort, and filter without changing the files in the archive. Settings → Library sets default Books, Folders, and Series presentation and which Smart Views appear. See Library browsing and selection for the available workflows.
