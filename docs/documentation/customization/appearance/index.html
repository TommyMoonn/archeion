Appearance and reader controls

Change app colors, reader typography, and the Library layout.

On this page

App themes control the Archeion interface. Reader settings control the page colors, text, and layout used while reading.

App appearance

#

Choose an app theme

#

Open Settings → Appearance and choose an App theme. Built-in themes are available immediately. Custom themes stored in Archeion's application data appear in the same selector across archives.

Use a custom theme

#

Custom themes can change supported app and reader colors. They cannot add CSS, scripts, fonts, images, or layout changes.

See Custom themes for setup and editing instructions.

Reader appearance

#

Choose reader colors

#

Choose a Reader theme from Settings → Appearance or from the Reader settings panel.

Change text and layout

#

Open Reader settings to change the typeface, text size, line spacing, page width, reading mode, and progress bar position. Custom theme files do not change these settings.

Library layout

#

Use the Library toolbar to switch between Grid and List view, change sorting, and apply filters. Settings also controls features such as Continue Reading and which Smart Views appear in the sidebar.
