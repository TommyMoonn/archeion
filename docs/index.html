Local-first

Your EPUBs stay as normal files.

Archeion keeps the archive understandable outside the app. Books and real folders remain yours to open, copy, move, and back up with ordinary filesystem tools.

  • annotations.json, library.json, progress.json
  • cover and scanner cache data
  • recovery and retained EPUB writeback backups
Stored separately

Archeion application data

Application-wide resources belong to Archeion itself rather than to any one EPUB archive.

  • Application-wide preferences
  • Installed dictionaries
  • Custom theme packages

Back up the complete archive, including .archeion/, to keep its books, archive metadata, and recovery data together.

  • No account
  • No cloud sync

Start with the EPUBs you already have.

Build from source Developer

Source setup is for contributors and developers. The Windows installer above is the recommended path for normal use. 

git clone https://github.com/TommyMoonn/archeion.git
cd archeion
npm install
npm run tauri:dev
