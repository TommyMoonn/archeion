Using Archeion

Manage books and folders

Rename, move, reveal, export, and delete real EPUB files and folders.

On this page

Archeion manages real files inside the active archive. File actions are designed to keep the Library and filesystem aligned.

Book file actions

Use a book action menu or Details drawer to rename, move, reveal, or delete an EPUB. Renaming and moving update the real path inside the archive.

Folder actions

The folder tree supports real folder creation and, when available, rename, move, reveal, and delete operations. Moving a folder also moves the EPUB files and nested folders inside it.

Delete behavior

Bulk deletion is presented as Delete to Recycle Bin. Review destructive confirmations carefully, especially when operating on multiple books or a folder with nested content.

If an EPUB has already disappeared outside Archeion, its action changes to Remove metadata so stale library state can be cleared without pretending a file was deleted.

Reveal in folder

Use Reveal in folder for books, folders, archives, or the themes directory when you need to inspect the actual files in Windows Explorer.

Export EPUBs

Selection mode can export selected EPUB files to another location without changing their archive paths. Annotation export is a separate action and supports Markdown or JSON.

Changes made outside Archeion

Archeion watches the active archive for relevant filesystem changes. Use Rescan archive when the Library needs an explicit reconciliation after external moves, renames, or additions.

Back up before large reorganizations

For a complete backup, copy the EPUB folders and the archive's .archeion directory together.
